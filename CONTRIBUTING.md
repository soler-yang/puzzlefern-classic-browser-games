# Contributing

Thanks for helping. To add a site:

1. It must be free to play in a browser, without a download.
2. It should work without an account (an optional account is fine).
3. No pop-up ads that interrupt a game in progress.
4. Add one line in the right section, in alphabetical order: `- [Name](link) - Short description ending with a period.`
5. One site per pull request, please.

If a site in the list stops working or changes for the worse, open an issue.
